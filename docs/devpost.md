# Codex x TwitchCon Hackathon

Build for streamers and their communities on Twitch with OpenAI Codex.

**Total prize pool: $25,000**  
**Top 5 projects:** Showcased on the Codex Booth stage at TwitchCon San Diego on November 15.

## Overview

Twitch is the home of shared live experiences, and developers shape how streamers and their communities experience them.

OpenAI and Twitch are teaming up to see what developers can build for the Twitch community with AI. In the Codex x TwitchCon Hackathon, participants will use **OpenAI Codex** to build useful and creative experiences for Twitch streamers and their communities.

Projects can give chat a way to play along, help streamers create together, or add something new to enhance streamed content. Participants will leave with a working project and hands-on experience building with Codex.

The top five projects will be showcased on the Codex Booth stage at TwitchCon San Diego on November 15, where winners will be announced live.

## Why Join?

- **$25,000 in prizes** and a spot on the TwitchCon stage for the top five projects.
- **Build with Codex:** Describe what you're building and let Codex help you get started with the Twitch API, EventSub, and chat.
- **Connect streamers and their communities:** Build something streamers and viewers can use live on stream.

## Getting Started

1. **Start with Codex:** [Sign in to Codex](https://chatgpt.com/codex/) and start a new thread for your project. You'll need its session ID when submitting.
2. **Explore Twitch development resources:** Visit [dev.twitch.tv](https://dev.twitch.tv/). If you're unsure where to start, follow the [Example Chatbot guide](https://dev.twitch.tv/docs/chat/chatbot-guide/) to get a chatbot running in minutes.
3. **Join the community:** Join the [TwitchDev Discord](https://discord.com/invite/G8UQqNy) and ask questions in the relevant channel. Introduce yourself in `#codex-twitchcon-hackathon` for general questions and updates.

# Requirements

## What to Build

Build for streamers and their communities on Twitch using OpenAI Codex.

The following are suggested directions to explore:

### 1. Streamer Collaboration
Help streamers talk, play, or create together on stream.

### 2. Audience Participation
Let chat join in through Twitch Plays games, live polls, streamer distractions, or other interactive experiences.

### 3. Content Enhancements
Build tools around what's being streamed, such as:

- A dice roller for tabletop streams.
- A live sports overlay.
- Tools for IRL and science streams.

These are starting points, not templates. Judges are looking for **original ideas**, so avoid simply rebuilding the examples above.

Projects can be ambitious or small and scrappy, as long as they:

- Connect to Twitch through technologies such as the Twitch API, EventSub, chat, Extensions, or overlays.
- Are built using OpenAI Codex.
- Provide a working experience for streamers and their communities.

## What to Submit

### 1. Code Repository

Provide a URL to your code repository on GitHub, GitLab, or Bitbucket.

The repository must contain all source code, assets, and instructions needed to run the project.

- Public and private repositories are accepted.
- Private repositories must be hosted on GitHub or GitLab and shared with [testing@devpost.com](mailto:testing@devpost.com).

### 2. Demo Video

Submit a video that:

- Is no longer than **3 minutes**.
- Demonstrates the project working on Twitch.
- Shows how OpenAI Codex was used during development.

The video must be uploaded to YouTube and publicly accessible.

### 3. Project Description

Provide a written description explaining the project's features, functionality, and how Codex was used.

### 4. Codex Session ID

Provide the Codex session ID for the thread in which most of the project was built.

- Type `/status` in Codex to find the session ID.
- If multiple threads were used, submit the ID of the thread where most of the development took place.

# Judging Criteria

## 1. Innovation / Idea
How creative and novel is the concept? Does the project differ from existing concepts?

## 2. Potential Impact
How useful or entertaining is the project for streamers and their communities?

## 3. Technological Implementation
How well is the project built, and how effectively does it use Codex?

## 4. Design
Is the project easy to use and fun to watch?
