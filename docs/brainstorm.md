- **StreamScript (Natural Language Automation):** A tool that lets streamers build complex broadcast automations using plain English instead of complicated node-based software. By leveraging Codex, it translates multi-step requests (e.g., "When a Hype Train hits Level 3, switch to the 'Party' scene, trigger confetti, and play an airhorn") into the exact execution scripts, JSON payloads, or API routing logic required by OBS WebSockets and Twitch EventSub.

- **HotMic Zero — Live streaming privacy firewall:** A privacy protection layer for streamers that detects and automatically masks sensitive information before it appears on the broadcast, including API keys, passwords, private messages, email addresses, and account details. It integrates with streaming software such as OBS, monitors selected screen regions, and applies configurable protection rules in real time. The goal is to prevent accidental information leaks without interrupting the stream.

- **StreamTwin — Virtual audience simulator for streamers:** A tool that lets streamers test their broadcast against different viewer profiles before making production changes. It analyzes overlays, scenes, layouts, captions, and visual elements to detect problems for mobile viewers, viewers with color-vision deficiencies, people relying on captions, low-bandwidth viewers, and newcomers unfamiliar with the content. It provides measurable diagnostics, previews of how the stream appears under different conditions, and suggested fixes. Changes can be tested before being applied to the live Twitch production.

- **The Living Stream — A Persistent Codex-Generated World Co-Authored by Chat**: Turn a Twitch channel into an evolving story-world where chat co-authors the narrative across streams. Viewers use free-form chat commands like `!explore`, `!talk to the merchant`, `!attack`, or `!build`; an EventSub chat listener sends each action to Codex, which interprets it against a saved JSON world state and returns structured consequences—narrative beats, new NPCs, stat changes, quests, or even small generated Canvas/JS mini-games that appear in the overlay. The streamer plays the protagonist while a polished overlay shows the current scene, inventory, and a growing “world chronicle.” Codex powers the command parser, world-state schema, event generation, and dynamic mini-game code synthesis, making it the real-time creative engine rather than just a dev assistant. This creates a new category of Twitch interaction: not a one-off chat game, but a persistent community narrative universe that rewards returning viewers and turns lurkers into collaborators. The demo can show a choice from a “previous stream” visibly shaping the current world, then a live chat action causing Codex to generate a new scene or mini-game on the spot—an instant stage-ready “wow” moment.
